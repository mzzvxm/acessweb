# AcessWeb

Um site simples e acessível sobre o movimento cultural da Tropicália (ou Tropicalismo) — desenvolvido como projeto fictício de portfólio.

## Sobre

O AcessWeb é um pequeno projeto frontend estático que visa demonstrar boas práticas de acessibilidade e usabilidade, assim como apresentar o conteúdo de forma clara e simples.  
Ele retrata o movimento Tropicália, com seção de introdução, galeria de imagens e formulário de contato.

> **Nota**: Este projeto é **fictício**, sem fins comerciais, apenas para fins de portfólio. :contentReference[oaicite:2]{index=2}

## Funcionalidades principais

- Controle de tamanho de fonte (“A+” / “A-”) para facilitar leitura. :contentReference[oaicite:3]{index=3}  
- Menu de navegação simples (“Início”, “Galeria”, “Contato”). :contentReference[oaicite:4]{index=4}  
- Seção de apresentação com título “Boas-vindas a” o tema. :contentReference[oaicite:5]{index=5}  
- Galeria de imagens que ilustram o movimento Tropicália. :contentReference[oaicite:6]{index=6}  
- Formulário de contato com campos: Nome, Email, Mensagem. :contentReference[oaicite:7]{index=7}  

## Tecnologias usadas

- HTML5  
- CSS3  
- JavaScript (simples para funcionalidades de acessibilidade)  
- Design responsivo e foco em acessibilidade.

## Como rodar localmente

1. Faça o clone deste repositório:  
   ```bash
   git clone https://github.com/mzzvxm/acessweb.git
```

2. Entre no diretório:

   ```bash
   cd acessweb
   ```
3. Abra o arquivo `index.html` em seu navegador favorito.

   ```bash
   open index.html
   ```

   ou arraste-o para o navegador.

## Estrutura de diretórios

```
/
├─ img/           ← imagens usadas no site  
├─ index.html     ← página principal  
├─ styles.css     ← estilos CSS  
└─ script.js      ← JavaScript de acessibilidade / interação  
```

## Acessibilidade

Algumas considerações adotadas para melhorar a acessibilidade:

* Botões para aumento/redução de fonte (“A+” / “A-”) para ajustar o tamanho de texto.
* Contraste de cores adequado para leitura.
* Uso de marcação semântica HTML5 para melhor compatibilidade com leitores de tela.
* Navegação simples, com menu fixo e clara hierarquia de títulos.
